    입력 방법
    • 원: x^2+y^2=25, (x-1)^2+(y+2)^2=9
    • 타원: x^2/9+y^2/4=1 · 포물선: y^2=4x, y=x^2-2x · 쌍곡선: x^2/4-y^2/9=1, xy=2
    • 다항: y=x^3-3x, y=(x-1)(x+2)^2
    • 유리: y=(2x+1)/(x-1), y=1/(x^2-1) (점근선이 점선으로 나와요)
    • 무리: y=sqrt(x+2), y=√(4-x^2), y=-sqrt(x)+1
    • 수식 입력(PC·휴대폰·태블릿 공통): 오른쪽 아래의 f(x) 둥근 버튼을 누르면 칠판 위에 떠 있는 수식 입력창이 열려요. 윗줄을 잡고 끌어서 옮기고, –로 줄이고, 수식홈 버튼으로 그래프 목록·설정을 열어요. 입력칸을 누르면 숫자·기호·함수 키패드가 나와요(기호/함수 탭). 휴대폰 기본 키보드를 쓰려면 키보드 버튼을 누르세요(다시 누르면 키패드). 이 패널의 새 식 입력칸을 누르면 좁은 화면에서는 같은 수식 입력창이 열리고, PC(넓은 화면)에서는 패널은 그대로 두고 화면 아래에 수식 키패드가 붙어요(키보드로 써도 돼요).
    • 접선: 그래프 줄 아래의 접선 버튼을 누른 뒤 기울기(예: 2), 접점(x좌표, 원·타원 등은 y도 가능), 곡선 밖의 점(P의 x, y) 중 하나를 고르고 값을 쓰면 접선과 방정식이 나와요. 분수(1/2)도 쓸 수 있어요. 접선은 y=f(x) 꼴과 이차곡선에서 쓸 수 있어요.
    • 지수: y=2^x, y=e^(x-1)+2, y=(1/2)^x
    • 로그: y=log2(x), y=log(x)(상용로그), y=ln(x)
    • 삼각: y=sin(x), y=2cos(3x)+1, y=tan(x)
    • 절댓값: y=|x-1|+2, y=abs(x^2-4) (기호 안에 기호가 또 들어가면 abs( )를 써요)
    • 구간별 함수: y=x^2 (x<1); 2x-1 (x>=1) — 구간은 ;로 나누고 조건은 (x<1), (0<=x<3) 꼴로 써요. 마지막에 조건 없는 식을 쓰면 나머지 구간이에요. 끝점은 포함이면 ●, 아니면 ○로 나와요. (<= 대신 ≤, ≥도 돼요)
    • 세제곱근: y=cbrt(x) 또는 y=x^(1/3) (x가 음수여도 실수 값으로 그려요)
    • 평행이동·대칭이동: 그래프 줄 아래의 이동·대칭 버튼을 켜면 도구가 도형 이동(S)으로 바뀌어요. 칠판에서 끌면 초록색 상(像)이 움직이고, x축·y축·원점·y=x 대칭 버튼으로 뒤집을 수 있어요. 이동한 식은 y-1=(x-2)^2 꼴로 보여 줘요. 목표(점선)를 고르거나 문제 내기를 누르면 점선 도형과 겹칠 때 🎉가 나와요.
    • 극값·변곡점: 그래프 줄 아래의 극값·변곡점 버튼을 누르면 화면 안의 극대·극소·변곡점을 점과 좌표로 표시해요 (y=f(x) 꼴).
    • 넓이: 넓이 버튼을 누르고 구간 [a, b]를 쓰면 색칠하고 정적분 값과 넓이를 계산해요. 아래 경계에 다른 식(예: x^2)을 쓰면 두 곡선 사이의 넓이예요. π, e, 분수도 쓸 수 있어요.
    • 슬라이더: 식에 a, b, c, d, h, k, m, n, p, q, r, t 글자를 쓰면 그래프 줄 아래에 슬라이더가 생겨요. 예) y=a(x-h)^2+k, x^2+y^2=r^2. 끌면 그래프가 바로 바뀌고, 숫자 칸으로 범위(왼쪽·오른쪽)와 값을 고칠 수 있으며 ▶를 누르면 저절로 움직여요. 값은 칠판과 함께 저장돼요.
    • 수식 편집기: 입력창에서 분수(/), 지수(^), 근호(√)를 모양 그대로 입력할 수 있어요. 터치 화면에서는 아래에 가상 키보드가 열리고, 입력칸 오른쪽 키보드 아이콘으로 열고 닫아요. 편집기를 불러오지 못하면 기존 입력창이 대신 열려요.
    • 공유: 저장 버튼 → 링크 복사를 누르면 칠판이 담긴 주소가 복사돼요. 받은 사람이 주소를 열면 같은 칠판이 보여요(서버에 저장하지 않아요). 필기가 많으면 그래프만 담고, 전부 보내려면 파일로 저장을 쓰세요.
    • 곱셈 기호는 생략할 수 있어요: 2x, (x+1)(x-1)
    • 지수나 함수의 값은 괄호로 묶으면 가장 정확해요: e^(2x), sin(2x)
    • π는 pi 또는 π로 쓰고, 자연상수는 e예요.
    • 도(°)를 고르면 x축 눈금이 15°~360° 단위로 바뀌고, 한 칸은 45°예요. 이때 원의 방정식은 모양이 찌그러져요.
